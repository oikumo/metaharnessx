# MHX promise

On opencode, given a change, show the constraints that apply, run the relevant
existing checks, and produce CI-trusted evidence — with durable project memory
(intent + checkpoint + AKB) that a fresh session can resume without prior chat.

Second user is the manager+agent loop itself: every process choice must survive
≤15 min review, agent execution without invented requirements, and fresh-session
resume from files alone.
